# Audit email changes and transfers

Email changes update the existing active user account so its identity, secret, and user space remain intact; they transfer submission and draft ownership to the new lowercase email. Every successful email change and administrative submission transfer records a compact immutable transfer log in SQL, including a successful transfer that moves no submissions; this replaces a separate inactive account as the history mechanism. A submission transfer validates users, loads its candidate submissions, and authorizes the caller for every candidate before creating a missing target account or modifying ownership. Because account data is in SQL while submissions and drafts are in Mongo, the operation uses pre-validation and compensating rollback, and publishes refresh events only after all persisted changes succeed.
